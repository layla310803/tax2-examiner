CAPITAL AND LIQUIDITY
CET1 Ratio = Common Equity Tier 1 Capital / Risk-weighted Assets
LCR = High Quality Liquid Asset Amount (HQLA) / Total Net Cash Outflows over next 30 days

RAROC
RAROC = (ROA - Expected Loss / Earning Assets) x (Earning Assets / Total Assets) x (Total Assets / Risk-Required Capital)
RAROC = One year net income on a loan / Capital at risk

DURATION (page 1)
D(perpetuity) = (1 + y) / y
D(annuity) = (1 + y) / y - T / ((1 + y)^T - 1)
D (coupon bond) = (1 + y) / y - ((1 + y) + T x (c - y)) / (c x ((1 + y)^T - 1) + y)
D(par bond) = ((1 + y) / y) x [1 - 1 / (1 + y)^T]
where y = yield, c = coupon rate, T = years to maturity

DURATION (page 2)
D = (Sum for t = 1 to N of CF x DF x T) / (Sum for t = 1 to N of CF x DF) = (Sum for t = 1 to N of PV x T) / (Sum for t = 1 to N of PV)
D (semi-annual cash flows) = (Sum for t = 1/2 to N of [CF_t x t / (1 + R/2)^(2t)]) / (Sum for t = 1/2 to N of [CF_t / (1 + R/2)^(2t)])

ALTMAN Z-SCORE
Z = 1.2 X1 + 1.4 X2 + 3.3 X3 + 0.6 X4 + 1.0 X5
X1 = Working capital / Total assets ratio
X2 = Retained earnings / Total assets ratio
X3 = Earnings before interest and taxes / Total assets ratio
X4 = Market value of equity / Book value of total liabilities
X5 = Sales / Total assets ratio

MARKET RISK AND PORTFOLIO THEORY
R_i = Sum for i = 1 to N of P_i x HR_i      (expected return: probability x holding-period return)
sigma_i = sqrt(sigma_i^2)
R_p = Sum for i = 1 to N of X_i x HR_i      (portfolio return: weight x holding-period return)
sigma_p = sqrt(X_i^2 x sigma_i^2 + X_j^2 x sigma_j^2 + 2 x X_i x X_j x sigma_i x sigma_j x rho_ij)
        (as printed on the sheet: sqrt(X^2_i sigma^2_i + X^2_j sigma^2_j b^2 + 2 Ki Kj sigma_i sigma_j rho_ij); the stray "b^2" and "K" are typos for the standard two-asset formula above)
rho_ij = sigma_ij / (sigma_i x sigma_j)
CV = sigma / mu      (coefficient of variation: standard deviation / mean)

LOAN PRICING
1 + k = 1 + (of + (BR + phi)) / (1 - [b x (1 - RR)])
where of = origination fee, BR = base lending rate, phi = risk premium, b = compensating balance requirement, RR = reserve requirement
